# Phantom Terminal v4.0.0 "Krypton" — Pure Native Shell Engine

Phantom Terminal v4.0.0 is a complete architectural overhaul. It eliminates all runtime dependencies (no Python, pip, sudo, or jq required) and provides 100% native execution across Windows PowerShell, Linux Bash, macOS, and Android Termux.

## Highlights

- **Release Codename "Krypton"**: Officially branded v4.0.0 as "Krypton", featuring modernized cyberpunk ASCII banners, dashboard telemetry, and interactive modals.
- **100% Unknown-Terminal Peer Parity**: First-class dual-identity support. Every Phantom command has an identical `unknown-*` equivalent (`unknown-help`, `unknown-dash`, `unknown-stealth`, `unknown-search`, `unknown-live`, `unknown-top`, `unknown-secrets`, etc.), dynamic help and cheat sheet adaptation when the Unknown theme is active, and dual environment variables (`UNKNOWN_QUIET`, `UNKNOWN_FORCE`, `UNKNOWN_SESSION_ACTIVE`, `UNKNOWN_HOME`, `UNKNOWN_PROFILE`).
- **Zero-Dependency Architecture**: 100% native shell scripts (`PhantomStartup.ps1` and `PhantomStartup.sh`). No external interpreters or package managers required.
- **Fail-Closed Release Verification**: Both fresh installations and runtime updaters enforce fail-closed cryptographic integrity using SHA-256 manifests and embedded root-of-trust digests (`EXPECTED_SHA256` / `$ExpectedSha256`).
- **Atomic Transactional Staging**: Downloads and updates stage to isolated temporary files, verifying AST syntax and cryptographic digests before touching any active installation or profile.
- **Pure SemVer Comparison**: Numerical semantic version comparison handling `v` prefixes, double-digit minor/patch versions (`3.10.0 > 3.9.0`), and pre-release identifiers (`4.0.0 > 4.0.0-beta`).
- **Precision 66-Column Dashboard HUD**: Unified box rendering with closed borders and visual width calculations that work accurately across UTF-8 locales and `LC_ALL=C`.
- **Instant Keypress Skip**: Startup animations can be immediately skipped by pressing Spacebar or Enter.
- **Subshell Loop Prevention**: `PHANTOM_SESSION_ACTIVE` detection prevents animation re-runs inside nested shells, tmux, or IDE subterminals.
- **AI Agent & CI Guard**: Automatic silent bypass when running inside GitHub Actions, CI pipelines, Claude Code, Cursor, or non-interactive pipes. Override with `PHANTOM_FORCE=1`.
- **Cyberpunk Stealth Mode**: Cloak your username, hostname, system specs, and paths on demand using `phantom-stealth on`.
- **Universal History Search**: Fast shell command predictor and history search (`phantom-search`) with automatic credential and secret token filtering.
- **Real-Time Live Telemetry**: Live updating system dashboard HUD with `phantom-top` or `phantom-dash -Live`.
- **Persistent Secrets**: Easter egg unlocks persist cleanly across sessions in `~/.phantom-terminal/.secrets`.
- **Zsh Login Shell Detection**: Automatic detection of user login shell (`$SHELL`), ensuring `.zshrc` is configured automatically on macOS and modern Linux Zsh setups.
- **Enhanced Credential Filtering**: Automated redaction of GitHub PATs, AWS access keys, Slack tokens, OpenAI keys, and MySQL credentials in history search (`phantom-search`).
- **Safe Updater Staging & Rollback**: In-place atomic promotion with automatic `.bak` backup rollback on PowerShell update failure.
- **Automated Test Engines**: Comprehensive test suites (67 automated tests: 31 PowerShell, 36 Bash) across PowerShell and Bash with 100% pass rates.

## Upgrading

Run `phantom-update` from inside your terminal or execute the universal installer:

```bash
# Bash (Linux / macOS / Termux)
curl -fsSL https://raw.githubusercontent.com/Unknown-2829/Phantom-terminal/v4.0.0/install.sh | bash
```

```powershell
# PowerShell (Windows / Linux / macOS)
irm https://raw.githubusercontent.com/Unknown-2829/Phantom-terminal/v4.0.0/install.ps1 | iex
```
