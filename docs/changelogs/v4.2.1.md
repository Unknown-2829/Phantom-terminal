# Phantom Terminal v4.2.1 "Krypton" — Changelog

- **AI Agent Guard Bypass Config**: Auto AI bypass active by default (`AIBypass: true`) to preserve tokens and eliminate transcript clutter, toggleable via `phantom-config aibypass on|off`.
- **VS Code Animation Control**: VS Code integrated terminal animations enabled by default (`AllowVSCodeAnimations: true`), toggleable via `phantom-config vscode on|off`.
- **Configurable Stealth Path Masking**: Real directory path shown by default in stealth mode; path cloaking (`~/phantom/core/grid`) toggleable via `phantom-config maskpath on|off`.
- **Interactive Configuration HUD**: Redesigned 66-column settings HUD with live toggles (`phantom-config [setting] on|off`), `-Reset`, and `-Edit`.
- **Precision Title Box Alignment**: Fixed right border alignment in title box across all platforms and font renderers.
- **Interactive Upgrade Modal**: Post-update modal waits for keypress (`Press any key to continue...`) and only displays to upgrading users, skipping fresh installations.
