# Phantom Terminal v4.1.0 "Krypton" — Release Notes

Phantom Terminal v4.1.0 builds on the zero-dependency pure native architecture introduced in v4.0.0, introducing dynamic theme-matched sci-fi telemetry rotation, precision terminal UI box border alignment, enhanced prompt spacing, and verified cross-platform installation stability.

## Highlights & Improvements

### 1. Theme-Matched Rotating Sci-Fi Telemetry
- **Dynamic Session-to-Session Identity**: When running in Stealth Mode (`phantom-stealth on` / `unknown-stealth on`), the Operator, Host, System Kernel, and Uptime metrics dynamically rotate on each new terminal session, matching the aesthetic of the active theme:
  - **Phantom Theme**:
    - **Operators**: `Ghost`, `Cipher`, `Spectre`, `Valkyrie`, `Null`, `Ronin`, `Phantom-0`
    - **Hosts**: `NEO-TOKYO-GRID`, `SHADOW-NET-CORE`, `ORBITAL-STATION-7`, `BLACK-ICE-NODE`, `NEURAL-MATRIX-01`, `PHANTOM-GATEWAY`
    - **Systems**: `Phantom OS v4.1.0 (Quantum Microkernel)`, `Phantom Neural Core v4.1.0 (Sub-atomic)`, `Phantom Mesh OS v4.1.0 (Encrypted)`, `Phantom Quantum Kernel v4.1.0 (Ring-0)`
    - **Uptime**: `∞ (Untraceable)`, `99.999% (Cloaked)`, `Sub-atomic Flux (Active)`, `Quantum Loop (Shielded)`
  - **Unknown Theme**:
    - **Operators**: `Anonymous`, `Unknown-2829`, `Root-Null`, `Operator-X`, `Enigma`, `Cipher-2829`, `Shadow-Ghost`
    - **Hosts**: `DARKNET-GATEWAY`, `ANONYMOUS-NODE-X`, `NULL-SECTOR-404`, `CIPHER-GRID-2829`, `SHADOW-RELAY-0`, `VOID-MATRIX-2829`
    - **Systems**: `Unknown Kernel v4.1.0 (Zero Footprint)`, `Unknown Mesh OS v4.1.0 (Dark-Routing)`, `Unknown Void Subsystem v4.1.0`, `Unknown Protocol v4.1.0 (Ephemeral)`
    - **Uptime**: `Redacted (Zero-Log)`, `Hidden Route (Active)`, `Ephemeral Loop (Active)`, `Zero-Trace (Cloaked)`
- **Dynamic Hardware Telemetry Flux**: Stealth CPU and RAM usage now feature a subtle randomized cyber flux per session (8–16% CPU, 12–22% RAM), breathing life into the dashboard HUD.
- **Thematic Prompt Paths**: When Stealth Mode is activated, the prompt path dynamically reflects the theme (`~/phantom/core/grid` for Phantom vs `~/unknown/darknet/grid` for Unknown).

### 2. Precision Box & Usage Bar Alignment
- **Usage Bar Border Flushness**: Eliminated right border overflow on CPU and RAM rows where `║` extended 1 cell past the 66-column boundary.
- **Font-Resilient Monospace Labels**: Standardized labels to `CPU:` and `RAM:` padded to exactly 10 characters, eliminating width ambiguities caused by emoji fallback on `⚙` and `☰`.
- **Vertical Bracket Alignment**: Opening brackets `[` and closing brackets `]` for CPU and RAM bars now align at identical display columns (column 14 and column 38).
- **Quote Row Padding Fix**: Corrected quote row left indentation so that the right border closes flush at column 66 without being pushed in by 1 character.
- **Skull Glyphs & Title Centering**: Accounted for the 2-cell display width of `☠` in modern terminal font engines (Cascadia Code, DirectWrite, CoreText, libvte), providing 2 spaces of breathing room (`☠  ...  ☠`).

### 3. Installer Box Alignment
- **Mathematical Centering in Installers**: Replaced hardcoded spacing in `install.ps1` and `install.sh` with dynamic centering algorithms for both the header banner and the completion summary box, ensuring all 3 borders (`╔═╗`, `║ ║`, `╚═╝`) align with 100% precision regardless of version string or codename length.

### 4. Enhanced Prompt Spacing
- **Clean Double-Spacing**: Added clean double-spacing between the status indicator (`✔` / `✘`) and prompt arrow (`»` / `>`) across PowerShell, Bash, and Zsh (`✔  » `), preventing visual crowding in modern monospace fonts.

### 5. Automated Engine Test Matrix
- Expanded comprehensive test suites (`tests/test_engine.ps1` with 33 tests, `tests/test_engine.sh` with 36 tests) validating SemVer comparison, stealth telemetry pools, installer fail-closed verification, credential filters, and visual length calculations with 100% pass rates (69/69 passed).

## Installation & Upgrading

### Single-Command Upgrade

```powershell
# Windows PowerShell (5.1+ / 7+)
irm https://raw.githubusercontent.com/Unknown-2829/Phantom-terminal/v4.1.0/install.ps1 | iex
```

```bash
# Linux / macOS / Android Termux (Bash / Zsh)
curl -fsSL https://raw.githubusercontent.com/Unknown-2829/Phantom-terminal/v4.1.0/install.sh | bash
```

Or from inside an existing Phantom Terminal session:
```bash
phantom-update
# or
unknown-update
```
