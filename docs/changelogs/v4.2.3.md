# Phantom Terminal v4.2.3 "Krypton" — Changelog

- **Interactive Installer for Linux, macOS, Termux & BSD**: Brought full interactive setup parity to `install.sh` matching Windows PowerShell, featuring a guided step-by-step wizard (theme, matrix mode, path, usage bars, animations, AI bypass, and update check).
- **Dual Installer Architecture**: Unified Express (instant defaults) vs Custom setup wizard across all platforms, with automatic non-blocking Express fallback in CI/piped runs (`curl | bash`, `irm | iex`).
- **VS Code Animation & Session Isolation**: Fixed VS Code animation playback via PID/TTY session tracking and modern VS Code environment markers, preventing parent process inheritance suppression.
- **Native BSD Platform Support**: Added explicit detection and system telemetry (`top`, `sysctl`) for FreeBSD, OpenBSD, NetBSD, and DragonFly BSD.
- **Multi-Tier JSON Fallback Validation**: Reliable structural JSON validation fallback using `jq`, `python3`, `node`, `perl`, and POSIX AWK.
- **Installer Configuration Recovery**: Safe timestamped backup of malformed existing configurations during installation without overwriting user data.
- **Stale Comment Headers**: Aligned all script comment headers across PowerShell and Bash engines to runtime version v4.2.3.
